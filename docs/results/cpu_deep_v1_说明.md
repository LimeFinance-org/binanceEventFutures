# CPU 深度训练 cpu_deep_v1 结果说明

- 配置：`config/cpu_deep.yaml`（22 核 CPU，无 GPU）；数据 2021-01-01 ~ 2026-11-09，每币种约 308 万分钟。
- 耗时：数据准备+特征研究 5 分钟，模型搜索 3.2 小时（全部试验完成，未用满 7 小时预算），
  候选样本外验证 1.2 小时，其余 0.5 小时；合计约 4.9 小时。
- 完整测试集报告见 `cpu_deep_v1_report.md`。

## 结论

1. 四项任务在独立测试集（最后 90 天）上信号胜率 56.3%~57.7%，均高于盈亏平衡 55.56%，**均未达到 70% 目标**。
2. 只有 ETHUSDT_10m 在考虑多重检验后仍显著（z=3.16 > 3.12）；其余三项的优势在统计上不能排除运气。
3. 入场延迟 1 分钟后胜率下降约 1~1.5 个百分点，BTC/ETH 10 分钟接近或低于盈亏平衡——实盘下单要尽量快。
4. 压力测试：胜率每打 2% 折扣，亏损概率升到 6%；打 5% 折扣，亏损概率 64%。优势很薄。
5. 验证期阈值曲线上，把阈值提高到 0.60~0.62 时胜率可到 65% 左右，但每天只有个位数信号，
   置信区间下界约 59%~60%，样本太少，系统按规则没有采用。
